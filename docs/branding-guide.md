# GitHub Profile Brand Identity Guidelines

## Brand Philosophy
Our brand represents Cloud Native Engineering, AI Agent Architectures, and Systems Integrity.

## Color Tokens
- **Background**: `#0d1117` (GitHub Dark Canvas)
- **Surface Card**: `#161b22`
- **Border**: `#30363d`
- **Primary Accent**: `#58a6ff` (Electric Azure)
- **Secondary Accent**: `#a371f7` (Neural Purple)
- **Text Primary**: `#f0f6fc`
- **Text Muted**: `#8b949e`

## Typography
- **Headings**: System Sans / Inter / Fira Code
- **Code & Metrics**: `Fira Code`, `SFMono-Regular`, `Consolas`

## Asset Guidelines
All SVGs located in `/assets/` follow responsive `viewBox` rules and support dark mode renders.
